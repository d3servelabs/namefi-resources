# Resources content

Content and shared assets consumed by the Namefi Resources application. English is the authoring source; locale folders hold translated counterparts.

```text
content/
  blog/       Articles by locale (see blog/README.md)
  assets/     Shared images (see assets/README.md)
  authors/    Byline profiles
  glossary/   Definitions and termbase sources
  tld/        Extension reference pages
  partners/   Partner profiles
  careers/    Job listings
```

Search writing work also updates English reference pages in `glossary/` and `tld/`. The three earlier search-opportunity articles are English articles. See `blog/en/README.md` for their scope. Publishing and translation follow the root agent guide and `.claude/rules/content.md`.
