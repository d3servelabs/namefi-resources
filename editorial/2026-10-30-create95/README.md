# The batch delivers 95 complete English articles

The user requested all 95 complete manuscripts after the earlier screening-only
review. Eight GPT-6.1-sol agents used high reasoning effort for focused writing
and independent cross-review. The runtime allowed seven simultaneous children;
the eighth started when a slot became available. The batch adds 56 English pages
and substantively revises 39 existing English pages. Four revisions concern TLD
references. The remaining pages belong to the blog collection.

The [article ledger](articles.json) preserves exact queries, cached demand,
DataForSEO difficulty, final titles, source URLs, and reviewed manuscript hashes.
The demand metric means approximate average monthly searches, not impressions.
The score divides demand by KD plus one. The score is an ordering heuristic;
KD does not measure the number of pages that answer a query.

## The writers answer distinct tasks with primary sources

Each manuscript opens with a direct answer and includes usable steps, decision
boundaries, and primary-source citations. Inline citations target semantic source
headings. Source notes link to precise external passages. Tool guides explain
actual official interfaces and do not invent executed lookup results.

Independent reviewers examined every manuscript in each assigned group. They
corrected source locators, registration-policy boundaries, current DMARC rules,
and provider-specific restrictions. Full source caches and individual audit
receipts remain in the local dated research workspace. This record does not
claim a re-audit of unchanged articles or translated prose.

## The batch preserves existing translations and publication controls

English articles publish independently. Existing translations remain present.
English source revisions can leave existing translated prose stale; this batch
records that limitation rather than pretending to translate the corpus.
Existing ordered relationship metadata remains unchanged. Added body links are
mirrored where the translated paragraph preserves the same meaning.

Articles and images are intentionally public. Editorial records remain
repository material and do not add public application routes. No endpoint,
account permission, or credential store changes.

## The release requires actual page and image verification

The batch uses the existing Resources PR, Astra submodule synchronization, and
checked-in deployment workflow. Local data, MDX, link, and whitespace checks
must pass before push. A merge or workflow dispatch alone does not prove a
production release. The publication ledger in the local research workspace
records per-page HTTP, image, citation-anchor, indexing-control, and recorded
headless-browser checks after the production deployment.
